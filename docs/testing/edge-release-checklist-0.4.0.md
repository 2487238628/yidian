# 12730 0.4.0 · Edge 发布验收

## 加载

1. 打开 `edge://extensions`，开启“开发人员模式”。
2. 选择“加载解压缩的扩展”，加载本仓库的 `extension` 文件夹。
3. 确认名称为“12730 · 文档回访伙伴”，版本为 `0.4.0`，没有红色错误。

## 普通网页手势

1. 打开一个普通 `https://` 网页，点击工具栏 12730 图标。
2. 宠物完整出现并缓慢巡游，到左右边缘会转身。
3. 按住宠物拖过 100px，松手后停在落点；分别拖到四个角，宠物不能越出视口。
4. 单击宠物打开卡片；卡片不覆盖宠物，也不越出视口。
5. 点击网页空白处，卡片关闭且网页原有点击仍可用。

## 产品闭环

1. 未记录页面显示 0%，点击“今天见过了 · 收下 25%”。
2. 进度变为 25%，刷新后仍保留。
3. 点击“安静陪伴”，宠物停止自主巡游但仍能拖动；再点“继续散步”恢复。
4. 点击“全部记录”，记录页能查看并打开原文。
5. 导出 JSON，再导入同一文件，不产生重复 URL。
6. 在记录页删除一份记录，确认其他记录不受影响。
