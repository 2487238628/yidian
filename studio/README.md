# 一点 · 重要的，不只见一次

在工作和学习中看到值得再见的网页或选段，Mark 一下；一点按 12730 节奏重新把它带到面前，宠物也随每次回来长一点。

## 在线体验

创空间提供可拖动宠物、Mark、四阶段成长和 12730 节奏演示。真实跨网页能力由下载后的 Edge 扩展提供。

## 隐私

扩展不读取未选择的网页正文，不发送产品数据到网络，不要求登录。它只在浏览器本地保存标题、网址、用户主动选择的文本、进度和回来时间。

## 当前能力

- 在普通网页中唤出、拖动和巡游；
- Mark 后立即获得 25%；
- 按 1、2、7、30 天完成四次相见；
- 一次只带回一条到期收藏；
- 本地查看、打开、删除、导入和导出收藏。

当前先把 Edge 闭环做稳；下一步用 Codex 实验工作上下文的 Mark 与回来，不提前建设通用多平台框架。
