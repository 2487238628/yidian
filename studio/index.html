  1. 1
    下载并解压

    保留解压后的文件夹，不要直接打开 ZIP。

  2. 2
    打开扩展管理

    Chrome 输入 chrome://extensions；Edge 输入 edge://extensions。然后开启开发人员模式。

  3. 3
    加载解压缩的扩展

    选择刚才解压得到的扩展文件夹。

  4. 4
    固定一点并开始使用

    在浏览器工具栏的“扩展”菜单里固定“一点”，再打开任意普通网页，点击图标收下一条。
