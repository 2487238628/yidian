# 一点｜工作与学习的收藏回看工具

> 重要的，不只见一次。

先做一点，就已经完成了四分之一。

如果一点确实帮你把一份重要内容重新带回了工作或学习，欢迎给这个开源项目一个 [Star](https://github.com/2487238628/yidian)。它会帮助更多人看见这个还很小的项目。

一点把你在工作和学习中收藏的重要内容，按 1、2、7、30 天重新带到面前。当前先支持 Chrome 和 Edge 电脑浏览器：收下整页或选段，立即获得 25%；以后再回来时，宠物也跟着长一点。

## 产品组成

- `extension/`：Manifest V3 浏览器扩展，当前支持 Chrome 和 Edge，负责跨网页收藏、再次带回和本地记录。
- `studio/`：ModelScope Static 创空间，负责公开互动演示、产品说明和扩展下载。
- `tests/`：调度、并发写入、注入恢复、交互、清单资源和创空间检查。

## 本地验证

```text
npm run check
```

当前正式版本为 `1.0.0`。ModelScope 下载包由 `extension/` 的同一份源码生成，ZIP 根目录直接包含 `manifest.json`。

## 隐私

扩展不读取未选择的网页正文，不发送产品数据到网络，不要求登录。浏览器本地仅保存标题、网址、用户主动选择的文本、进度、回来时间和宠物设置。

## 1.0.0 已包含

- 收下整页或选段，并保存主动选择的文字上下文
- 按 1 / 2 / 7 / 30 节奏回来，进度从 25% 长到 100%
- 一次只带回一条到期内容，不制造新的提醒积压
- 网页宠物巡游、拖动与安静陪伴
- 我的收藏：总数、今天可回来、已经长成
- 查看进度、重开来源、删除记录
- JSON 本地备份的导入与导出
- 无需登录，记录只保存在浏览器本地
