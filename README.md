# 12730 · 文档回访伙伴

先做一点，就已经完成了四分之一。

12730 是一只住在网页里的文档回访宠物。用户在 Notion、ima、飞书或普通网页上 Mark 当前文档，立即获得 25%；宠物再按 1、2、7、30 天把原文带回来。

## 产品组成

- `extension/`：Manifest V3 Edge 网页扩展，负责跨网页 Mark、巡游、回访和本地记录。
- `studio/`：ModelScope Static 创空间，负责公开互动演示、产品说明和扩展下载。
- `tests/`：调度、并发写入、注入恢复、交互、清单资源和创空间检查。

## 本地验证

```text
npm run check
```

当前版本为 `0.4.0`。ModelScope 下载包由 `extension/` 的同一份源码生成，ZIP 根目录直接包含 `manifest.json`。

## 隐私

扩展不读取网页正文，不发送产品数据到网络，不要求登录。浏览器本地仅保存标题、网址、进度、回访时间和宠物设置。

## 当前范围

已包含：稳定 Mark、12730 回访、一次一份到期文档、网页宠物巡游与拖动、安静陪伴、记录查看/打开/删除/导入/导出、ModelScope 互动展示。

下一步：经过真实 Edge 扩展手势验收后，再加入大小调节、轻量皮肤与更多低打扰状态动画。
