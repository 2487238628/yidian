# 一点 · 重要的，不只见一次

先做一点，就已经完成了四分之一。

一点把你在工作和学习中 Mark 的重要内容，按 12730 节奏重新带到面前。当前先从 Edge 网页开始：Mark 整页或选段，立即获得 25%；以后再回来时，宠物也跟着长一点。

## 产品组成

- `extension/`：Manifest V3 Edge 网页扩展，负责跨网页 Mark、巡游、回访和本地记录。
- `studio/`：ModelScope Static 创空间，负责公开互动演示、产品说明和扩展下载。
- `tests/`：调度、并发写入、注入恢复、交互、清单资源和创空间检查。

## 本地验证

```text
npm run check
```

当前正式版本为 `1.0.0`。ModelScope 下载包由 `extension/` 的同一份源码生成，ZIP 根目录直接包含 `manifest.json`。

## 隐私

扩展不读取未选择的网页正文，不发送产品数据到网络，不要求登录。浏览器本地仅保存标题、网址、用户主动选择的文本、进度、回来时间和宠物设置。

已包含：整页或选段 Mark、12730 回来节奏、一次一条到期内容、网页宠物巡游与拖动、安静陪伴、记录查看/打开/删除/导入/导出、ModelScope 互动展示。
