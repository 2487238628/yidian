# 一点 · 12730 文档回访伙伴

一点帮助计划很多、容易卡在开始的人，把“系统学习”缩小成一次轻松的开始：在当前文档 Mark 一下，立即获得 25%；网页宠物再按 12730 回访节奏把原文带回来。

## 在线体验

创空间提供可拖动宠物、Mark、四阶段成长和 12730 节奏演示。真实跨网页能力由下载后的 Edge 扩展提供。

## 隐私

扩展不读取网页正文，不发送产品数据到网络，不要求登录。它只在浏览器本地保存标题、网址、进度和回访时间。

## 当前能力

- 在普通网页中唤出、拖动和巡游；
- Mark 后立即获得 25%；
- 按 1、2、7、30 天完成四次相见；
- 一次只带回一份到期文档；
- 本地查看、打开、删除、导入和导出记录。

项目仍在持续迭代。下一步包括宠物大小调节、轻量皮肤、更多低打扰动画与可选 AI 回忆问题。
